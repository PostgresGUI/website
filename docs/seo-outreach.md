# PostgresGUI listing and review outreach

The goal is accurate inclusion and independent evaluation, not paid links or
generic guest posts. Send each request individually after checking the target's
current submission rules.

| Priority | Target | Action | Evidence to provide |
| --- | --- | --- | --- |
| 1 | [PostgreSQL Clients wiki](https://wiki.postgresql.org/wiki/PostgreSQL_Clients) | Request or make a factual open-source Mac client entry. | GitHub repository, App Store page, supported PostgreSQL workflows, current screenshot |
| 2 | [Community Guide to PostgreSQL GUI Tools](https://wiki.postgresql.org/wiki/Community_Guide_to_PostgreSQL_GUI_Tools) | Add PostgresGUI to the interactive client section without comparison claims. | macOS requirement, PostgreSQL-only scope, license, source URL |
| 3 | [awesome-postgresql](https://github.com/sroeschus/awesome-postgresql) | Open a small pull request adding PostgresGUI under GUI tools if it meets the maintainer's criteria. | Repository URL, one-sentence description, open-source license |
| 4 | [MacUpdate](https://www.macupdate.com/help) | Submit the current Mac App Store release or correct any existing listing. | App Store URL, version, macOS requirement, privacy statement |
| 5 | [AlternativeTo](https://alternativeto.net/software/postgresgui/) | Correct stale features, screenshots, license, and pricing; ask active users for honest reviews. | Current screenshots, GitHub URL, App Store URL |
| 6 | [Bytebase PostgreSQL GUI roundup](https://www.bytebase.com/blog/top-postgres-gui-client/) | Offer a review build and a factual feature matrix for independent consideration. | Clear limitations, one-time price, native Swift implementation, no telemetry |
| 7 | [QueryPlane PostgreSQL client roundup](https://queryplane.com/blog/top-postgresql-gui-clients/) | Ask the editor to evaluate PostgresGUI for a future update. | Review build, screenshots, source code, comparison methodology |

## Short request structure

1. State that you build PostgresGUI.
2. Explain why it fits the target list in one sentence.
3. Link the product page and source repository.
4. Include two verifiable facts and one important limitation.
5. Ask for evaluation or correction, not a guaranteed link.

Do not claim that PostgresGUI supports autocomplete, schema diff, backup and
restore, visual query plans, or multiple database engines unless those features
ship and are verified in the current release.
